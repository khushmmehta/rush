# RushEngine
### A WIP rendering/game engine based on Rust & WGPU.

The original repository is located and maintained at [Codeberg](https://www.codeberg.com/khush/rush). The [GitHub repository](https://www.github.com/khushmmehta/rush) is simply a mirror & you are requested to submit any issues or PRs directly to the Codeberg repository.

The purpose of this engine is to advance development in performant, no-compromises realtime rendering.
